# ParcelTrack — GitHub Ready Demo

## Files
- `index.html` — customer tracking page
- `admin.html` — shipment management dashboard

## How to run
1. Upload both files to a GitHub repository.
2. Enable GitHub Pages.
3. Open `index.html`.
4. Open `admin.html` to add/edit/delete shipments.

## Important
This version is a **frontend demo**. Data is stored in the browser's `localStorage`, so it is not a real multi-user backend. For a real business system, connect the admin/customer pages to a secure backend/database and add authentication.
